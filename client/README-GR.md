## 📖 Περιγραφή Έργου
Η παρούσα εφαρμογή αποτελεί έναν επιστημονικό προσομοιωτή που μελετά την **Πιθανότητα Αποκλεισμού (Blocking Probability - Pb)** σε τηλεπικοινωνιακά δίκτυα επόμενης γενιάς (6G).

Ο προσομοιωτής επιλύει το πρόβλημα κατανομής πόρων σε συστήματα πολλαπλών υπηρεσιών (Multi-rate Loss Systems), χρησιμοποιώντας επαναληπτικές μεθόδους (Iterative Algorithms) και λαμβάνοντας υπόψη φυσικούς παράγοντες όπως ο θερμικός θόρυβος και οι παρεμβολές.

Η πλατφόρμα επιτρέπει στον χρήστη να παραμετροποιήσει τη χωρητικότητα των συνδέσμων (Fronthaul, Server, Antennas) και τις απαιτήσεις των υπηρεσιών, να εκτελέσει πειράματα σε πραγματικό χρόνο και να εξάγει δεδομένα για ανάλυση.

## 🚀 Τεχνολογίες & Αρχιτεκτονική

Το σύστημα ακολουθεί αρχιτεκτονική **Microservices** τριών επιπέδων:

### 1. Frontend (Client)
* **React.js (Vite):** Σύγχρονο περιβάλλον χρήστη (UI) υψηλής απόδοσης.
* **Recharts:** Βιβλιοθήκη για τη δυναμική οπτικοποίηση των αποτελεσμάτων (Line Charts).
* **Bootstrap 5:** Πλαίσιο CSS για Responsive σχεδιασμό.
* **Axios:** Διαχείριση ασύγχρονης επικοινωνίας με το Backend API.

### 2. Backend (Server)
* **Python (Flask):** REST API Server που εκτελεί την επιχειρησιακή λογική.
* **NumPy:** Χρήση διανυσματικών υπολογισμών (Vectorization) για ταχεία εκτέλεση.
* **Algorithms:** Υλοποίηση των KRF και RLA με προστασία αριθμητικής σταθερότητας.

### 3. Database & Caching
* **MongoDB:** NoSQL βάση δεδομένων για την αποθήκευση ιστορικού.
* **Smart Caching:** Έλεγχος ύπαρξης προηγούμενων πειραμάτων για άμεση ανάκτηση αποτελεσμάτων (O(1)) χωρίς επανάληψη υπολογισμών.

## 🔬 Επιστημονική Μεθοδολογία

Ο πυρήνας της προσομοίωσης βασίζεται στα εξής μαθηματικά μοντέλα:

1.  **Kaufman-Roberts Formula (KRF):**
    Αναδρομικός υπολογισμός της κατανομής κατάληψης πόρων σε έναν σύνδεσμο.
2.  **Reduced Load Approximation (RLA):**
    Επαναληπτική μέθοδος (Erlang Fixed Point Approximation) για την εύρεση της ισορροπίας του δικτύου.
3.  **End-to-End Blocking (BPC):**
    Συνδυασμός των πιθανοτήτων αποκλεισμού των επιμέρους συνδέσμων.

## ⚙️ Τεχνικές Βελτιστοποιήσεις & Διαφορές με τη Διατριβή

Η παρούσα εφαρμογή αποτελεί την **Software Υλοποίηση** της Πτυχιακής Διατριβής.
Ωστόσο, ο κώδικας έχει δεχθεί **περαιτέρω τεχνικές βελτιστοποιήσεις** σε σχέση με την αρχική ακαδημαϊκή μελέτη, με στόχο τη μέγιστη αριθμητική ευστάθεια σε συνθήκες ακραίου φόρτου.

Συγκεκριμένα, έχουν προστεθεί οι παρακάτω μηχανισμοί:

### 1. Αριθμητική Σταθερότητα (Dynamic Scaling)
Σε δίκτυα με μεγάλο φόρτο (>1000 Erlang), οι πιθανότητες κατάστασης μπορούν να υπερβούν τα όρια κινητής υποδιαστολής. Εφαρμόστηκε μηχανισμός δυναμικής κλιμάκωσης (scaling) για την αποφυγή `Overflow`.

### 2. Απόσβεση Ταλαντώσεων (Damping)
Εισήχθη παράγοντας απόσβεσης (Damping Factor 0.5) στον αλγόριθμο Erlang Fixed Point για την εξάλειψη των ταλαντώσεων κατά τη σύγκλιση σε συνθήκες συμφόρησης.

### 3. Αυστηρότερη Σύγκλιση
Η παρούσα έκδοση απαιτεί απόλυτη σύγκλιση (`tolerance < 0.0001`) για κάθε υπηρεσία σε κάθε σύνδεσμο ξεχωριστά, σε αντίθεση με προσεγγιστικές μεθόδους μέσου όρου.

> **Παρατήρηση:** Λόγω των παραπάνω βελτιώσεων ακρίβειας, τα αποτελέσματα της προσομοίωσης ενδέχεται να εμφανίζουν μικρές αποκλίσεις (ελαφρώς υψηλότερες/πιο συντηρητικές τιμές Blocking) σε σχέση με τα διαγράμματα που παρουσιάζονται στο PDF της διατριβής.
