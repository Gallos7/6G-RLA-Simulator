(constant) PRESETS :Object

Dictionary of pre-defined simulation scenarios used to quickly populate the input forms. Data Structure Definition: - id {string}: Unique identifier for the scenario. - label {string}: Display name shown in the UI dropdown. - description {string}: Short explanatory text describing the scenario's purpose. - variable {string}: The independent variable for the X-axis (e.g., 'load', 'server'). - target {number}: The stop condition value for the independent variable. - step {number}: The increment size for the simulation loop. - K {number}: Number of Service Classes (Services). - M {number}: Number of Network Links (Topology size). - load {number}: Initial Traffic Intensity (Erlang). - a_resource {Array}: Capacity Vector C = [C1, C2, ... CM]. Represents channels per link. - r_resource {Array>}: Requirement Matrix (b_kj). Rows=Services, Cols=Links. - enableNoise {boolean}: Whether to inject Gaussian noise into the simulation. - noiseMantissa {number}: Scientific notation base for noise. - noiseExponent {string}: Scientific notation exponent for noise.
